# Lyao Talk 2.3.6 validation report

Status: release candidate; final gates are recorded below.

## Scope

This update includes the changes since 2.3.5, including media upload and
encoding fixes, chat-history deletion behavior, navigation changes, OMEMO
group sender handling, and removal of both XEP-0402 and legacy XEP-0048 room
bookmarks when leaving a group. The client waits for server confirmation before
removing the room from its interface.
