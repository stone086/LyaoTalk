# Lyao Talk 2.3.7 validation report

Date: 2026-11-02 (Asia/Shanghai)

## Scope

This patch release assigns a new version to the production changes made since
2.3.6. Notable changes include remembered Web device authentication and
revocation, mobile notification and reconnect improvements, public group
discovery, group media sharing, member listing, and conversation details fixes.
The release also removes the unused AI tab from the conversation details panel.

Version metadata is aligned in `VERSION`, both package manifests, the Web
lockfile, `.env.example`, the README, and the map tile/search user agents.
