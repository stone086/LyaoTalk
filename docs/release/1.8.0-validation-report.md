## Known limitation

Python `--require-hashes` is not enabled in `install.sh` yet because package hashes must be generated against exact resolved wheel/sdist artifacts by `pip-compile --generate-hashes` on an online trusted builder. This release adds the policy, input file, validation gate, and CI workflow; the next sub-release can flip install-time `--require-hashes` after hashes are generated and verified.
