# LiaoT 2.3.3 Validation Report

Version: 2.3.3
Name: preflight-hardening

## Purpose

This release adds interactive preflight configuration so common staging install failures are caught before destructive installation begins.

## Added

- `scripts/liaot_env_lib.sh`
- `scripts/env_wizard.sh`
- `scripts/env_validate.sh`
- `scripts/preflight_check.sh`
- `docs/runbook/preflight.md`

## Key behavior

- Missing secrets are auto-generated by the wizard.
- `DOMAIN` and `EMAIL` are prompted interactively.
- OIDC, LDAP, and external Prometheus settings are prompted only if enabled.
- `install.sh --configure` runs configuration only and exits.
- `install.sh` can start the wizard when `.env` is missing in an interactive shell.
- API admin plaintext password is hashed after the API venv exists if the system Python cannot hash it earlier.
