# LiaoT 2.0.0 Validation Report

Release: `2.0.0-performance-baseline`

## Scope

This release adds performance baselining tools rather than changing the chat
feature surface:

- k6 load-test examples for public API endpoints.
- SQLAlchemy query counting for N+1 detection.
- slow SQL structured log events.
- PostgreSQL index/hot-query review scripts.
- performance baseline documents and release gate script.
