- The first fresh-install attempt exposed a real issue: the previous Python
  hash lock was generated for CPython 3.13 wheels, while staging uses Python
  3.10. The repaired lock now includes the Python 3.10 wheel hashes needed by
  staging.
- Non-interactive SSH install left firewall prompts at their default `no`, so
  UFW was not reset during remote validation.
