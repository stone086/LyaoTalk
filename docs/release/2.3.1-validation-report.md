# LiaoT 2.3.1 Validation Report

This release is an audit hotfix over 2.3.0.

## Fixed

- `install_coturn` was running before certificates existed and before the API EnvironmentFile existed. It now runs after `setup_ssl`.
- `TURN_SECRET` is generated before Prosody config is rendered, then reused by coturn and API runtime config.
- API EnvironmentFile now receives `ADMIN_PASS_HASH` instead of plaintext `ADMIN_PASS`.
- API EnvironmentFile now propagates SSO/LDAP, observability, performance and SFU settings.

## Validation

- Shell syntax checks passed.
- Python compileall passed.
- Frontend `npm ci`, `npm run build`, `npm test -- --run`, and production high audit passed.
- Local validation scripts passed.

## Remaining limitations

- No real VPS/staging install was executed in this environment.
- Python hash lock remains generated on CPython 3.13 Linux x86_64; regenerate on the target Python ABI if necessary.
- k6 runtime load tests require a staging host with k6 installed.
